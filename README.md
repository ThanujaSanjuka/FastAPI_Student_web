# Student Database Web Microservice (FastAPI & Docker)

A simple, modern, and containerized web-based microservice built using Python **FastAPI** and **Docker**. It allows users to interactively add student records through a clean web interface and view persistent data stored in real-time.

## 🚀 Features
- **Web UI Interface:** Easy-to-use HTML/CSS form for entering student details (ID, Name, GPA).
- **File Persistence:** Automatically saves and displays student records from `student_database.txt`.
- **Dockerized Environment:** Fully containerized for instant deployment and testing on any machine.
